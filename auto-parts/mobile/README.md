# تطبيق الجوال (أندرويد وآيفون)

غلاف [Capacitor](https://capacitorjs.com) يفتح المنصة المنشورة (`server.url` في `capacitor.config.json`). أي تحديث للموقع يظهر في التطبيق فورًا، ولا يحتاج التطبيق إعادة بناء إلا عند تغيير الغلاف نفسه: الأيقونات، الإعدادات، الإضافات، الأذونات.

| | |
|---|---|
| معرّف التطبيق | `sa.chinesecarparts.app` (يثبت نهائيًا بعد أول رفع للمتجر) |
| الاسم على الشاشة | قطع الغيار الصينية |
| بلا اتصال | صفحة `www/offline.html` بزر إعادة المحاولة |
| الكاميرا | حقول الصور في الموقع تفتح الكاميرا أو المعرض (أذونات أندرويد و`Info.plist`) |
| شاشة البداية والأيقونات | تُولّد من `assets/` بالأمر `npm run assets` |

## البناء

- **أندرويد (تلقائي):** كل تغيير في `auto-parts/mobile` يشغّل `.github/workflows/auto-parts-android.yml`، ويرفع `app-debug.apk` في Actions ← آخر تشغيل ← Artifacts. نسخة التجربة تُثبّت على أي جوال أندرويد بعد السماح بالتثبيت من مصادر غير معروفة.
- **أندرويد (محليًا):** `npm ci && npm run android:debug` (يحتاج JDK 21 وAndroid SDK 36).
- **آيفون:** يحتاج macOS وXcode. بلا ماك يُبنى عبر خدمة سحابية (مثل Codemagic) من مجلد `ios/`، مع شهادة توقيع من حساب Apple Developer.

## قبل الرفع للمتاجر

1. نسخة release موقّعة: مفتاح توقيع أندرويد (keystore) يُحفظ خارج المستودع، وشهادات أبل.
2. الإشعارات الفورية: الإعداد في README الرئيسي ← «الإشعارات الفورية». يلزم `GOOGLE_SERVICES_JSON` لأندرويد، ومفتاح APNs لآيفون.
3. صفحات المتجر: الوصف، لقطات الشاشة، رابط سياسة الخصوصية، بيانات أمان البيانات (Google) وملصق الخصوصية (Apple)، وحساب تجريبي لمراجعي أبل.
4. حذف الحساب متوفر من صفحة «حسابي» (شرط أبل).
