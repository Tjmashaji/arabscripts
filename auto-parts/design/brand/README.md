# هوية المنصة

الشعار ترس يتحول إلى سهم (توريد وتوصيل) وفي وسطه صامولة. اللون البرتقالي هو لون أزرار المنصة (`#c2410c`)، بتدرّج من `#e8590c` إلى `#9a3412`.

| الملف | الاستخدام |
|---|---|
| `icon.svg` | الأيقونة بزوايا دائرية: الموقع والعروض |
| `icon-full.svg` / `store-icon-1024.png` | أيقونة متجر أبل وقوقل: مربع كامل بلا شفافية، والمتجر يدوّر الزوايا بنفسه |
| `icon-maskable.svg` | أيقونة أندرويد التكيفية (الرمز داخل المنطقة الآمنة) |
| `glyph.svg` / `glyph-white.svg` | الرمز وحده بالبرتقالي أو الأبيض (أيقونة الإشعارات، الخلفيات الداكنة) |
| `logo-horizontal.png` | الشعار مع الاسم بالعربي والإنجليزي |
| `play-feature-graphic-1024x500.png` | صورة الواجهة المطلوبة في Google Play |

أيقونات الموقع في `public/icons` و`src/app/icon.svg` و`src/app/apple-icon.png` و`src/app/favicon.ico`.
