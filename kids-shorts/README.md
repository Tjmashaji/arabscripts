# استوديو شورتس الأطفال (kids-shorts)

منصة عربية لصنع مقاطع تعليمية قصيرة للأطفال (YouTube Shorts) ونشرها مباشرة على قناتك في يوتيوب:
اختر الدرس ← عدّل المشاهد بمعاينة فورية ← أضف الصوت ← صدّر فيديو عموديًا 1080×1920 ← انشره على يوتيوب «مخصصًا للأطفال».

> مشروع مستقل داخل المستودع `arabscripts`، ولا يمس `masari/` أو `arab-scripts/` أو `ad-studio/` (يعيد استخدام أسلوب التصدير العربي والخطوط من `ad-studio`).

## ما يعمل وما يحتاج إعدادًا

| الوظيفة | الحالة |
|---|---|
| الحسابات والجلسات (scrypt، كوكي httpOnly، حد للمحاولات، CSRF) | تعمل |
| دروس جاهزة: ٢٨ حرفًا، الأرقام ١–١٠، ٨ ألوان، الأشكال، ٨ حيوانات، ٥ آداب وعادات، و٩ دروس دينية (أركان الإسلام والإيمان، الصلوات، الوضوء، آداب الطعام، السلام، أذكار النوم، العطاس، بر الوالدين) بلا موسيقى افتراضيًا ودون تصوير للذات الإلهية أو الملائكة أو الأنبياء | تعمل دون أي مفتاح، ومختبرة لكل موضوع وعمر |
| محرر المشاهد (نص كبير، جملة مسموعة، رسوم من مكتبة 150+ رسمًا، ألوان، ترتيب، تكرار، حفظ تلقائي) | يعمل |
| التسجيل بصوتك من المتصفح أو رفع ملف (قص الصمت تلقائيًا وقياس المدة الفعلية) | يعمل |
| موسيقى خلفية مولّدة برمجيًا بلا حقوق طرف ثالث (هادئة/مرحة) مع خفضها تحت الصوت | تعمل |
| التصدير عبر FFmpeg (عربية سليمة عبر libass، رسوم متحركة، انتقالات، ترجمة، تحقق من الناتج) | يعمل ومختبر |
| ربط يوتيوب (OAuth) والرفع القابل للاستئناف، الجدولة، وسم «مخصص للأطفال» | يعمل ومختبر بخادم Google مُحاكى؛ **يحتاج `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET`** |
| المخرج الذكي لمواضيع حرة (Claude) | **يحتاج `ANTHROPIC_API_KEY`**؛ بدونه يبدأ الموضوع الحر بمشاهد فارغة تكتبها بنفسك |
| الصوت الذكي (ElevenLabs) | **يحتاج `ELEVENLABS_API_KEY` و`ELEVENLABS_VOICE_ID`** |

لا توجد محاكاة لأي خدمة خارجية: الخدمة غير المتصلة تظهر «غير متصلة» في الإعدادات وتُعطَّل أزرارها.

## المتطلبات

- Node.js 22.13 أو أحدث (يستخدم `node:sqlite` المدمج، فلا حاجة لخادم قاعدة بيانات)
- FFmpeg وffprobe مع libass وlibharfbuzz وlibfribidi وlibx264 (حزمة ffmpeg في Ubuntu/Debian تكفي)

## التشغيل محليًا

```bash
cd kids-shorts
npm install
cp .env.example .env.local    # ثم ضع TOKEN_ENCRYPTION_KEY (الأمر داخل الملف)
set -a && . ./.env.local && set +a

npm run dev       # التطبيق على http://localhost:3000
npm run worker    # العامل الخلفي (طرفية ثانية): التصدير والصوت والرفع
```

قاعدة البيانات والملفات تُنشأ تلقائيًا في `DATA_DIR` (افتراضيًا `./data`).

## ربط يوتيوب

1. في [Google Cloud Console](https://console.cloud.google.com/): أنشئ مشروعًا وفعّل **YouTube Data API v3**.
2. اضبط «OAuth consent screen» وأضف بريدك كمستخدم اختبار ما دام التطبيق في وضع الاختبار.
3. أنشئ «OAuth client ID» من نوع **Web application** وأضف رابط العودة: `APP_URL/api/youtube/callback` (يظهر بالضبط في صفحة الإعدادات).
4. ضع `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` في البيئة، وأعد التشغيل، ثم «ربط قناة يوتيوب» من الإعدادات.

ملاحظات مهمة من سياسات يوتيوب:
- المقاطع التي ترفعها مشاريع API **غير مُراجَعة** (منذ يوليو 2020) تُقفل على «خاص» حتى يجتاز المشروع تدقيق التزام YouTube API Services. للنشر العام عبر المنصة اطلب التدقيق من Google.
- الرفع يستهلك جزءًا كبيرًا من الحصة اليومية للمشروع؛ تجاوزها يعيد المهمة لاحقًا تلقائيًا.
- كل مقطع يُرفع بـ `selfDeclaredMadeForKids: true` بعد تأكيد صريح من المستخدم (قانون COPPA): تُعطَّل التعليقات والإعلانات المخصصة. ويُفصح بـ `containsSyntheticMedia` عند استخدام الصوت الذكي.
- الجدولة: يُرفع المقطع «خاصًا» مع `publishAt`، ويصبح عامًا تلقائيًا في الموعد.
- رمز التحديث يُخزَّن مشفرًا بـ AES-256-GCM (`TOKEN_ENCRYPTION_KEY`)، والفصل يلغيه لدى Google.

## البنية

```
src/lib/          المجال المشترك: الدروس الجاهزة، مكتبة الرسوم، المخططات والحدود
src/app/          الصفحات (عربي RTL) ومسارات API رقيقة: تحقق zod ← خدمة ← JSON
src/server/
  db.ts           SQLite (WAL) والمخطط
  services/       المشاريع، المهام، التصديرات، يوتيوب، النشر
  media/          FFmpeg: ASS للعربية، الموسيقى المولّدة، محرك التصدير
  providers/      Claude (مخرجات منظمة + إصلاح صارم)، ElevenLabs
  youtube/        OAuth والرفع القابل للاستئناف
src/worker/       العامل: يحجز المهام ذريًا، يعيد المحاولة بتأخير متزايد، ويستعيد مهام عامل متوقف
assets/           الخطوط (OFL) والرسوم (Twemoji، CC-BY 4.0)
```

- **المهام**: مهمة نشطة واحدة لكل نوع ومشروع (فهرس فريد)، فالنقر المزدوج لا ينشئ تصديرًا أو رفعًا مكررًا. الرفع يحفظ رابط الجلسة ويُستأنف من آخر بايت استلمه يوتيوب.
- **الصوت**: محفوظ لكل مشهد مع النص الذي سُجّل له؛ تعديل الجملة يجعل الصوت «لا يطابق» ويمنع التصدير حتى يُعاد.
- **التصدير**: مقطع صامت لكل مشهد ثم تركيب نهائي (انتقالات + ASS + مزج الصوت + loudnorm −14 LUFS)، ثم التحقق من الأبعاد والمدة ووجود الصوت والصورة.
