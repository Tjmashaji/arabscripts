# مساري: ملف المشروع الكامل

**آخر تحديث:** 15 أكتوبر 2026
**الحالة باختصار:** النظام شغال ومكتمل الأدوار، والأمان قوي ومختبر. بقي قبل الإطلاق العام (القائمة الكاملة في قسم «الباقي»):
- بريد خاص (SMTP).
- تجربة الإشعارات على جوال حقيقي.
- نشر التطبيق في المتاجر.

## 1) ما هو مساري؟

منصة سعودية لإدارة وتتبع النقل المدرسي. تربط في نظام واحد:
- ولي الأمر؛
- السائق؛
- المدرسة؛
- برج المراقبة؛
- الإدارة التنفيذية (المنطقة)؛
- مدير النظام.

| البند | القيمة |
|---|---|
| الموقع | https://masari-zeta.vercel.app |
| صفحة حذف الحساب (للمتاجر) | https://masari-zeta.vercel.app/#delete-account |
| سياسة الخصوصية | https://masari-zeta.vercel.app/#privacy |
| المستودع | `Tjmashaji/arabscripts` ← مجلد `masari/` |
| قاعدة البيانات | Supabase، مشروع `hramsoavpanetdhwpokr` |
| الاستضافة | Vercel (تُنشر تلقائيًا عند الدمج في `main`) |
| تطبيق الجوال | Capacitor 8، بالحزمة `sa.masari.app` لأندرويد والآيفون |

### التقنيات
- **الواجهة:** React وTypeScript وVite، عربية بالكامل من اليمين لليسار، مع مفتاح للإنجليزية، وتعمل كتطبيق ويب (PWA).
- **الخادم:**
  - Supabase: قاعدة Postgres مع صلاحيات على مستوى الصف (RLS)، ودوال خادم آمنة.
  - pg_cron للمهام المجدولة، وpg_net للاتصال بالخارج.
  - ثلاث دوال طرفية (Edge Functions) تعمل على Deno.
- **الخرائط:** Leaflet مع خرائط OpenStreetMap.
- **الإشعارات:**
  - Web Push للمتصفح.
  - Firebase (FCM) لأندرويد.
  - Apple (APNs) للآيفون.
  - SMS وواتساب عبر Twilio أو Unifonic، عند إضافة المفتاح.

## 2) ما يقدر يسويه كل دور الآن

### 👨‍👩‍👧 ولي الأمر
- **تتبّع الباص:**
  - يتابع الباص مباشرة على الخريطة أثناء رحلة ابنه فقط.
  - يرى الوقت المتوقع للوصول ومراحل الرحلة.
  - يوصله إشعار عند بدء الرحلة، واقتراب الباص، وصعود ابنه، ووصوله، ونزوله.
- **أبناؤه:**
  - يرى أبناءه، وطلب تسجيل ابن جديد، وتحديد موقع المنزل (والتغيير يحتاج اعتماد المدرسة).
- **غياب ونداء:**
  - تسجيل غياب.
  - نداء البوابة، والتصاريح: استلام بنفسه أو خروج مبكر.
- **مع المدرسة:**
  - محادثة مع المدرسة، وفواتير رسوم النقل، وملاحظات وتقييم.
- **روابط ومشاركة:**
  - رابط تتبّع مؤقت يشاركه مع شخص آخر.
  - يقدر يفعّل SMS وواتساب لأهم التنبيهات.
- **جديد:**
  - **تذاكر الدعم الفني:** زر «تواصل معنا» صار يشتغل.
  - **شريط الإعلانات.**
  - **«تنزيل بياناتي»** تطبيقًا لنظام حماية البيانات الشخصية.
  - **حذف الحساب.**

### 🚌 السائق
- **رحلة اليوم:**
  - خريطة بمحطات مرقمة، ومسار على الطرق، والملاحة إلى المحطة التالية.
  - بدء الرحلة وإنهاؤها.
  - **موقعه يُرسل حتى والشاشة مطفأة** في تطبيق أندرويد.
- **المحطات والطلاب:**
  - اعتماد المحطة بالموقع: لازم يكون قريبًا منها وبدقة GPS جيدة.
  - تسجيل الصعود والنزول يدويًا أو بمسح بطاقة الطالب.
- **السلامة:**
  - فحص السلامة قبل الرحلة.
  - بلاغ طارئ بموقع الباص الفعلي.
- **إصلاحات PR #17:**
  - **يعود GPS تلقائيًا** إذا أُغلق التطبيق أثناء الرحلة.
  - **يعمل بدون إنترنت:**
    - تبقى شاشة الرحلة.
    - تُحفظ العمليات وتُرسل لاحقًا.
    - العمليات الفاشلة تظهر للسائق، ما تختفي بصمت.
  - **زر «تخطي المحطة»** مع سبب.
  - البلاغ الطارئ ما يقول «تم الإرسال» إلا بعد الحفظ الفعلي.
- **سجل الرحلات.**

### 🏫 المدرسة (مدير المدرسة، التشغيل، مشرف النقل، موظف البوابة، برج المراقبة)
- **الطلبات:**
  - إضافة طالب أو سائق، واعتماد طلبات أولياء الأمور والسائقين.
  - **جديد:** «اعتماد الكل» و**استيراد الطلاب من ملف Excel**:
    - قالب جاهز ومعاينة قبل الاستيراد.
    - كل سطر خاطئ يظهر برقمه وسببه.
- **الطلاب:**
  - إسنادهم للمسارات، وبطاقات QR للطباعة، وصورة الطالب، وإعادة إصدار البطاقة المفقودة.
  - **جديد:** بحث يتجاهل الهمزات، وتصفية (بلا مسار، بلا موقع منزل، موقوفون، الصف)، وتقسيم القائمة إلى صفحات.
  - **جديد: ملف الطالب:**
    - الفصل وجهة الطوارئ.
    - **أكثر من ولي أمر.**
    - **إيقاف مؤقت** و**انسحاب** بسبب يصل لولي الأمر.
- **الباصات والسائقون:**
  - وثائق الباص (الاستمارة والتأمين والفحص) والصيانة، ورخصة السائق.
  - **جديد:** تعديل بيانات السائق، و**إيقافه وإعادته** بسبب يصل له.
- **المسارات:**
  - إنشاء مسار وتعديله وحذفه، ومخطط مسارات تلقائي.
  - أوقات المحطات، وأقصر ترتيب، ونقاط تجمع، وأيام التشغيل، ونسخ المسار، وورقة للسائق.
  - مقارنة المخطط بالفعلي.
- **رحلات اليوم:**
  - السائق البديل، وإلغاء الرحلة.
  - **جديد:**
    - **إنشاء تلقائي كل صباح 4:30**، مع ملخص للمدرسة بما تعذّر إنشاؤه وسببه.
    - الرحلة الملغاة لها زر «إعادة إنشاء».
    - الزر ما يقبل الضغط مرتين.
- **الإجازات:** تقويم إجازات يوقف إنشاء الرحلات في أيامها.
- **فحوصات السلامة اليومية.**
- **برج المراقبة:**
  - الرحلات الجارية، والباصات المنقطعة، والبلاغات، وتنبيهات «خارج المسار» و«توقف طويل».
- **أدوات أخرى:**
  - نداء البوابة، والمحادثات مع أولياء الأمور، ورسوم النقل مع التذكير.
  - التقارير الشهرية مع تصدير Excel، وتقييم السائقين.
  - فريق المدرسة وأدواره، واشتراك مساري وفواتيره.
- **جديد:**
  - اختيار المدرسة لمن يعمل في أكثر من مدرسة. هذا أصلح خطأ كان يفتح مدرسة غلط.
  - طلب ترقية الباقة.
  - تذاكر الدعم.

### 🏛️ الإدارة التنفيذية (المنطقة)
- نظرة على مدارس منطقتها، ودليل المدارس، وتفعيل المدارس.
- برج المراقبة لمنطقتها، والتقارير، وخريطة التأخير.
- **جديد:**
  - يوصلها إشعار بكل بلاغ طارئ في منطقتها.
  - تقدر **تستلم البلاغ وتغلقه**.
  - ما ترى مناطق غيرها، وهذا مختبر.

### 🛠️ مدير النظام
- **الإدارة الأساسية:**
  - دليل المدارس، والمستخدمون والصلاحيات (منح الأدوار، والإيقاف المؤقت أو الدائم، والحذف).
  - إدارة البيانات: تعديل أي سجل.
- **الاشتراكات والسجلات:**
  - الاشتراكات والباقات والفواتير.
  - سجل الأعطال، وإحصاءات الرسائل.
- **جديد في هذه الجلسة:**
  - **الدخول كـ مدرسة أو سائق أو ولي أمر:**
    - يرى التطبيق كما يراه صاحبه، وكل دخول مسجل في سجل التدقيق.
    - شاشة السائق وولي الأمر للعرض فقط، وما تشتغل GPS باسم السائق.
  - **صحة النظام:**
    - المسارات اللي ما انعملت لها رحلة اليوم وسببها.
    - الباصات اللي انقطع موقعها.
    - الرسائل الفاشلة والأعطال.
    - الرخص والوثائق اللي بتنتهي خلال 30 يومًا.
  - **الدعم الفني:** صندوق التذاكر والرد عليها، والرد يصل إشعارًا لصاحب التذكرة.
  - **الإعلانات:** لكل المستخدمين أو لفئة أو لمنطقة. تصل إشعارًا وتظهر شريطًا حتى تنتهي.
  - **أدوات الحساب:**
    - إرسال رابط كلمة المرور، وإعادة إرسال رابط التفعيل.
    - **تسجيل خروج من كل الأجهزة**: يصير تلقائيًا مع الإيقاف.
    - **دمج حساب مكرر.**
  - **نقل سائق أو طالب بين المدارس:** الطالب ينتقل مع أولياء أمره.
  - **سجل التدقيق:**
    - بحث بالمستخدم والإجراء والتاريخ، وتصدير CSV.
    - **تسجيل كل دخول للنظام** (كان لا يُسجَّل).
  - **الإيرادات:**
    - الإيراد الشهري، والمحصّل، والمستحق، والمتأخر.
    - الاشتراكات اللي قرب تنتهي، والمدارس القريبة من حد الباقة.
    - تذكير تلقائي قبل انتهاء الاشتراك بأسبوعين، وتحويل الاشتراك إلى «متأخر» إذا تأخرت الفاتورة أسبوعًا.
  - **حدود الباقة يفرضها الخادم:** عدد الباصات والطلاب، بعد ما كانت تحذيرًا في الشاشة فقط.
  - **إصلاح خطأ:** تعديل الاشتراك كان يرجّع تاريخ بدايته لليوم.
  - **دور «برج مراقبة المدرسة»:** صار يُمنح من شاشة المستخدمين، وصار يقدر يغلق التنبيهات.

## 3) الأمان والجودة

- **الصلاحيات:** RLS مفروضة على كل الجداول، وكل الدوال الحساسة تتحقق من صلاحية المستدعي.
- **سد ثغرة في هذه الجلسة:** المدرسة كانت تقدر تربط سجل سائق أو ولي أمر بحساب أي شخص بالتعديل المباشر. الحين هذا الربط لا يتم إلا من دوال الخادم.
- **العزل:** كل مدرسة ما تشوف إلا بياناتها، وكل منطقة ما تشوف إلا مدارسها، وولي الأمر ما يشوف إلا أبناءه.
- **لا أسرار في الواجهة:** مفتاح Supabase العام فقط، ومفاتيح Firebase وApple محفوظة في أسرار Supabase.
- **الاختبارات:** تشتغل تلقائيًا مع كل تعديل في GitHub Actions (`masari-ci`)، وكلها ناجحة. وقت آخر تحديث للملف:

| النوع | الأمر | العدد |
|---|---|---|
| قاعدة البيانات | `npm run test:db` | 5 ملفات: `isolation` و`school_day` و`school_ops` و`school_profiles` و`admin_suite` (123 فحصًا) |
| الوحدات | `npm test` | 19 اختبارًا |
| الدخان في متصفح حقيقي | `npm run test:smoke` | 101 فحص لكل الأدوار |
| أخرى | `npm run typecheck` · `npm run lint` | نظيفة |
| تطبيق أندرويد | يُبنى تلقائيًا | ملف APK في GitHub Actions |

### ✅ ولي الأمر: أُنجزت (15 أكتوبر)
كل بنود ولي الأمر من تقرير الفحص:
- **الغياب:** «ابني غائب اليوم» يشمل الذهاب والعودة، ويُحفظ تصريحًا لأي رحلة تُنشأ لاحقًا.
- **الملاحظات والشكاوى:**
  - الشكوى بلا تقييم نجوم.
  - «تم الإرسال» بعد الحفظ فعلًا.
  - الطالب يُرسل برقمه.
  - السجل يبقى بعد الدخول.
  - المدرسة ترد، والرد يصل إشعارًا ويظهر لولي الأمر.
- **لوحة الرحلة:**
  - لا أحداث وهمية.
  - عنوان رحلة العودة «إلى المنزل».
  - الموقع القديم يظهر «آخر موقع قبل N د» بدل «GPS مباشر».
- **التنبيهات والدفع:**
  - شاشة اختيار أنواع التنبيهات في «حسابي».
  - الضغط على الإشعار يفتح صفحته.
  - طريقة الدفع (الآيبان) تظهر في الفاتورة.
- **باقي:** فتح الصفحة المناسبة عند الضغط على **إشعار الجوال** نفسه، وهذا يحتاج تحديث دالة `push`.

### 🟠 المدرسة
- **مسار ثانٍ للباص:** فترتين صباحيتين لنفس الباص، ما يقدر حاليًا.
- **حفظ آمن:** مخطط المسارات ودمج المحطات يحتاجون حفظًا في عملية واحدة، حتى ما يبقى مسار ناقص لو فشلت خطوة.
- **إسناد جماعي:** إسناد عدة طلاب لمسار مرة وحدة.
- **الأداء:** صفحة المسارات تفتح خريطة لكل مسار دفعة وحدة، وكل عملية تعيد تحميل كل البيانات.

### 🟠 السائق: «وضع القيادة»
- بطاقة كبيرة للمحطة التالية.
- أزرار 56 بكسل بدل 32.
- زر طوارئ بضغط مطوّل.
- الشاشة تبقى مضاءة أثناء الرحلة.

### 🟡 أنظمة ناقصة
| النظام | الحالة | الجهد |
|---|---|---|
| **الدفع الإلكتروني** (Moyasar أو Tap أو HyperPay) والفاتورة الإلكترونية (ZATCA) | السداد بتحويل يدوي فقط | كبير |
| **برج مراقبة بالخريطة** (فلاتر، حالات «متحرك/متوقف/متأخر»، تنبيه صوتي، تحديث فوري) | قائمة فقط | كبير |
| **حذف تلقائي كامل للبيانات القديمة** | يغطي المواقع والإشعارات المقروءة فقط. ما يشمل السجلات القديمة ورقم هوية الطالب في الطلبات القديمة | متوسط |
| **تنبيه فشل المهام المجدولة والنسخ الاحتياطي** | غير موثق | صغير |

### 🔵 الأمان والأداء والوصول
- **الأمان:**

- **الإنجليزية:** تغطي جزءًا قليلًا من النصوص.
