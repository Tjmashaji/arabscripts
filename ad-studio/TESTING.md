## ما تغطيه الاختبارات

### `tests/unit/logic.test.ts` (13 اختبارًا)
- ضبط مجموع مدد المشاهد على المدة المطلوبة بالضبط، والتعامل مع مدد غير صالحة.
- توزيع سيناريو المستخدم على المشاهد دون فقد أي كلمة.
- القوالب تحذف الأسطر التي تعتمد على حقل فارغ، ولا تخترع عرضًا أو سعرًا.
- تصحيح مخرجات المخرج: حذف مراجع ملفات غير موجودة، وتصحيح انتقال غير معروف، ورفض مخرجات بلا مشاهد كخطأ قابل لإعادة المحاولة.
- المحاكاة لا تضيف خصومات أو أسعارًا.
- **انحدار مهم**: التحديث الجزئي للمشهد لا يضيف قيمًا افتراضية تمسح الحقول غير المرسلة (خلل اكتُشف وأُصلح أثناء التطوير).
- تحديد نوع الملف من البايتات، ورفض HTML وSVG.
- منع حقن أوامر ASS في نصوص الفيديو، وتقسيم الترجمة.

### `tests/unit/providers.test.ts` (7 اختبارات، بشبكة مُحاكاة)
- **Claude**: شكل الطلب (النموذج، المخطط المنظم، `fallbacks`، ترويسة beta، وسم `<brief>`، وتعليمات عدم ذكر عرض غير موجود)، وتصحيح المخرجات، وحساب التكلفة من `usage`. الرفض والمفتاح الخاطئ يعطيان خطأً غير قابل لإعادة المحاولة برسالة عربية.
- **Runway**: اختيار `image_to_video` أو `text_to_video`، والمقاس والمدة، وقص البرومبت عند 1000 حرف، وتحويل حالات المهمة (التقدم، النجاح، الفشل)، والتكلفة التقديرية.
- **ElevenLabs**: المسار والترويسة والنموذج والسرعة، والتكلفة بعدد الأحرف، وخطأ 429 قابل لإعادة المحاولة و401 غير قابل.

### `tests/integration/security.test.ts` (7 اختبارات، قاعدة حقيقية)
- مستخدم لا يرى مشاريع غيره، ولا يعدّلها، ولا يدرج مشاهد أو مهام في مساحته. التحقق يتم على مستوى RLS نفسه.
- لا يرى ملفات غيره، ولا يعدّل مشاهده، ولا يرفع إلى مشروعه.
- دور المشاهد (`viewer`) يقرأ ولا يعدّل.
- جدولا الجلسات وحدود الطلبات غير مقروءين، ولا يرى المستخدم حسابات غيره.
- مفتاح منع التكرار يعيد نفس المهمة.
- سجل الاستخدام لا يحتسب المهمة مرتين.

### `tests/integration/pipeline.test.ts` (3 اختبارات، قاعدة + FFmpeg + العامل)
- **سيناريو القبول: إعلان مطعم 30 ثانية** بأسلوب ترندي وراوٍ صوتي ومقاس 9:16:
  1. رفع مقاطع وصور حقيقية وشعار وموسيقى مرخّصة.
  2. «لدي فكرة جاهزة» بنص السيناريو المطلوب، فيتوزع على خمسة مشاهد بالتوقيت `0–4، 4–9، 9–16، 16–24، 24–30`، ويُستبدل `[اسم المطعم]` بالاسم الفعلي.
  3. تعديل مشهد، ورفض التعديل المتزامن القديم.
  4. التصدير قبل إسناد المواد يكشف خمس مشاكل.
  5. إسناد مواد حقيقية لأربعة مشاهد، وتوليد المشهد الخامس (محاكاة).
  6. إعادة الترتيب، ثم التعليق الصوتي لكل مشهد (محاكاة).
  7. الموسيقى والشعار والترجمة.
  8. **ملف نهائي صالح**: 1080×1920، مدته 30 ثانية (±0.25)، بمسار صوت، ويحمل وسم المحاكاة.
- ملف مشهد محذوف من التخزين يظهر كمشكلة واضحة، ومهمة التصدير تفشل برسالة مفهومة دون استثناء غير معالج.
- رفض ملف مزيّف (HTML باسم jpg)، ورفض فيديو مرفوع كشعار، دون ترك ملفات في التخزين.

### `tests/e2e/restaurant.spec.ts` (2 اختباران، متصفح حقيقي)
- **الرحلة الكاملة من الواجهة**:
  1. التسجيل، ثم بيانات النشاط.
  2. الرفع، بما فيه نافذة ترخيص الموسيقى ورفض ملف مزيّف.
  3. الإعداد ومسار «لدي فكرة جاهزة»، ثم توليد السيناريو.
  4. خمسة مشاهد بمجموع 30 ثانية، وتعديل النص على الشاشة وحفظه تلقائيًا.
  5. إسناد المواد وتوليد مشهد وتعليق صوتي لكل المشاهد.
  6. المونتاج (الموسيقى والشعار مع حفظ تلقائي).
  7. التصدير وتنزيل ملف `video/mp4` حقيقي.
  8. فتح صفحات المهام والقوالب والإعدادات.
- **العزل والحماية**: مستخدم ثانٍ يحصل على 404 من الـ API ومن الصفحة لمشروع غيره، وطلب معدِّل من أصل آخر يُرفض بـ 403 (CSRF).

## التشغيل

```bash
# قاعدة اختبار نظيفة (تحذف ad_studio_test وتعيد إنشاءها)
PGPASSWORD=<postgres> ./tests/global-db.sh
npm test

# المتصفح: شغّل التطبيق والعامل أولًا مع ALLOW_SIMULATION=true، و SIGNUP_LIMIT_PER_HOUR مرتفع
npm run build && npm start &   # أو npm run dev
npm run worker &
npm run test:e2e
# لحفظ لقطات الشاشة لكل خطوة:
E2E_SHOTS=/path/to/dir npm run test:e2e
```

## ما لم يُختبر ولماذا

| البند | السبب |
|---|---|
| Claude وElevenLabs وRunway على الخدمات الحية | لا توجد مفاتيح في بيئة التطوير. المحوّلات مختبرة بشبكة مُحاكاة فقط، والتشغيل الحي هو أول بند في `IMPLEMENTATION_PLAN.md` |
| جودة النطق العربي واللهجة | تعتمد على صوت المزود المختار، ولا يمكن قياسها دون مفتاح |
| الأداء تحت حمل عالٍ وأكثر من عامل متزامن | `SKIP LOCKED` مصمم لذلك، لكن لم يُشغَّل اختبار حمل |
| متصفحات غير Chromium وأجهزة جوال حقيقية | الواجهة متجاوبة، وفُحصت بلقطات شاشة على Chromium فقط |
