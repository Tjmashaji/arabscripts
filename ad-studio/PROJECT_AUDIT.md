# فحص المشروع قبل التنفيذ — استوديو الإعلانات الذكي

تاريخ الفحص: 16 أكتوبر 2026. الفرع: `claude/busy-maxwell-qdsk7y`.

## 1. ما يحتويه المستودع

المستودع `arabscripts` مستودع متعدد المشاريع (monorepo) يضم مشروعين مستقلين، ولا يوجد فيه أي مشروع لإنتاج الإعلانات:

| المجلد | المشروع | التقنيات | الحالة |
|---|---|---|---|
| `arab-scripts/` | متجر «عرب سكربتس» لبيع سكربتات FiveM وتراخيصها | Next.js 16.2، Prisma، NextAuth (Credentials + JWT)، Tailwind 4، shadcn | نسخة MVP تجريبية |
| `masari/` | «مساري» لإدارة النقل المدرسي | Next.js 16.2 (vinext)، Supabase (Auth + Postgres + RLS + Edge Functions)، Capacitor للجوال | منتج قيد الإطلاق، له CI في `.github/workflows/masari-ci.yml` |

### ملاحظات على المشاريع القائمة (لم تُعدَّل)

- **arab-scripts:** ملف `prisma/schema.prisma` يعلن `provider = "postgresql"` بينما الملف `prisma/dev.db` المحفوظ في المستودع قاعدة SQLite. هذا تعارض يجعل تعليمات README (`npx prisma db push`) لا تطابق الملف المحفوظ. لا يوجد `.env.example` رغم أن README يطلب نسخه. صفحة الدفع «نظام محلي للمحاكاة» وكلمات مرور تجريبية ضعيفة موثقة في README. ما زال يستخدم `middleware.ts` الذي أصبح مهجورًا في Next.js 16 لصالح `proxy.ts`.
- **masari:** مشروع مستقل بقاعدة بيانات Supabase خاصة به. لا علاقة له بالإعلانات، والفيديوهات الإعلانية لمساري صُنعت سابقًا خارج المستودع.

## 2. القرار

- لا يمكن بناء «استوديو الإعلانات الذكي» داخل أي من المشروعين دون تغيير هويتهما، لذلك أنشأنا مشروعًا مستقلًا في `ad-studio/` (بموافقة صاحب المشروع)، دون لمس `arab-scripts/` أو `masari/`.
- الخلفية: PostgreSQL مع عامل خلفي (worker) للمهام الطويلة، وتخزين ملفات خلف واجهة قابلة للاستبدال (بموافقة صاحب المشروع). السبب: يمكن تشغيل المنصة واختبارها بالكامل محليًا، بما فيها FFmpeg، وتُنشر على أي خادم يدعم Postgres.

## 3. البيئة المتاحة فعليًا

| الأداة | الحالة |
|---|---|
| Node.js | 22.22 |
| Next.js | 16.4.2 (`proxy.ts` بدل `middleware.ts`، طلبات async) |
| PostgreSQL | 16.15 محليًا |
| FFmpeg / FFprobe | متاح، ومبني مع libass وharfbuzz وfribidi وlibx264، أي يدعم كتابة العربية المتصلة RTL داخل الفيديو |
| Chromium + Playwright | متاح لاختبارات الواجهة |
| مفاتيح خدمات الذكاء الاصطناعي | غير متوفرة في البيئة. لذلك تعمل المنصة في «وضع المحاكاة» الموسوم بوضوح حتى تُضاف المفاتيح |

## 4. المخاطر التقنية

1. **توليد الفيديو بالذكاء الاصطناعي** يتطلب مزودًا خارجيًا مدفوعًا (Runway وغيره). المحوّل مكتوب وفق وثائق المزود، لكنه لم يُختبر على الخدمة الحية لعدم توفر مفتاح.
2. **جودة الصوت العربي** تعتمد على المزود. ElevenLabs يدعم العربية، لكن اللهجة السعودية غير مضمونة لكل صوت.
3. **التكلفة:** أي مستخدم غير مصرح له يستطيع استنزاف رصيد المزود. لذلك وضعنا حدًا للإنفاق لكل مساحة عمل، وحدًا لمعدل الطلبات، ومفاتيح منع التكرار.
4. **تسرب الملفات بين المستخدمين:** عولج بسياسات RLS داخل Postgres نفسه، ومسار ملفات يتحقق من العضوية، وروابط مؤقتة موقعة.
5. **العامل الخلفي ومعالجة الفيديو** لا يعملان على Vercel Serverless. يحتاجان خادمًا أو حاوية (Railway أو Fly أو VPS).
